# 2p2t Voice

- https://2p2t.org
- https://voice.2p2t.org
- https://github.com/2p2t-Official/2p2t-voice/releases

## Install

1. Fabric Loader
2. Fabric API
3. `2p2tvoice-0-loader-*.jar` → `.minecraft/mods`

Alt: `2p2tvoice-*+<mc>.jar`

## Build

```bash
./scripts/build-loader.sh
./scripts/build-one.sh 1.21.11
```

JDK 21 → 1.21.x  
JDK 25 → 26.x
